# MD TikTok Downloader (Android)

1. Create a new GitHub repo and push everything in this folder (keep the `.github` folder).
2. Open the repo > **Actions** > **Build Android APK** (it also runs on every push to main).
3. When it turns green, open the run and download the **MD-TikTok-Downloader-apk** artifact (zip), then unzip it.
4. Install `app-debug.apk` on your phone (allow "install unknown apps").

Usage: in TikTok tap **Share** > **MD TikTok Downloader** (if you don't see it, tap **More**).
The lion + ring animation shows fetching and downloading, then the file lands in Movies/MD TikTok.
